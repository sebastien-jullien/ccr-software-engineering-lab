# COUCHE B — la porte

## 7. Ce qui est ouvert

```text
PORTE HUMAINE DE DIRECTION R&D POSTÉRIEURE À LA MISSION 013
= OUVERTE
```

L'autorité 71 laisse ouvertes deux questions matériellement distinctes :
RCS-B et RCS-C. Le programme dispose donc de deux directions R&D possibles
réellement différentes, et la sélection humaine est appropriée.

## 8. Option de direction A

```text
DIRECTION OPTION A
= ADDRESS_M13_CONSTITUTIVE_RESPONSIBILITY_EXHAUSTION_SEMANTICS

CIBLE
= RCS-B
= QU-01
```

Question canonique :

```text
QUELLE SÉMANTIQUE CONSTITUTIVE POSITIVE,
S'IL EN EXISTE UNE,
DÉFINIT LA FACTORISATION COMPLÈTE
D'UN CANDIDAT ADMISSIBLE DE LA MISSION 013
EN RESPONSABILITÉS MATÉRIELLES INDÉPENDANTES ?
```

L'option A doit tenir distinctes :

```text
INVARIANT SÉMANTIQUE COMPLET
DÉCOMPOSITION CONSTITUTIVE COMPLÈTE
```

```text
ELLE NE REFAIT PAS
« OÙ LES DIFFÉRENCES ENTRE CANDIDATS SONT OBSERVABLES »
CETTE QUESTION EST DÉJÀ FERMÉE
```

## 9. Portée exacte de l'option A

Une étude ultérieure sous l'option A pourra porter sur la sémantique de :

```text
ce qui compte comme responsabilité constitutive
ce qui compte comme indépendance
ce qui compte comme dérivation
ce qui compte comme structure composite
quand plusieurs facteurs constitutifs peuvent alimenter
  une même réponse gouvernante
quand un facteur n'est qu'un paramétrage ou une représentation
comment tout facteur constitutif admissible se projette
  sur le modèle de réponses gouvernantes déjà gelé
comment classer les facteurs constitutifs apparents à venir
comment la factorisation est positivement close,
  sans queue OTHER ouverte
```

Elle doit préserver :

```text
MCS-B          ESTABLISHED
RG-1..RG-8   GELÉES
```

Elle ne doit pas inférer :

```text
UNE RÉPONSE GOUVERNANTE
= UNE RESPONSABILITÉ CONSTITUTIVE
```

## 10. Frontière de succès de l'option A

Une étude ultérieure réussie sous l'option A pourrait établir :

```text
EXHAUSTION DES RESPONSABILITÉS CONSTITUTIVES
= ESTABLISHED

et donc potentiellement

RCS-B
= ESTABLISHED
```

Elle n'établirait PAS automatiquement :

```text
RCS-C
RCS-D / RCS-E / RCS-G / RCS-H
l'univers complet de candidats M13
MULTIPLE
ni aucune sémantique gouvernante d'espace de responsabilités
```

## 11. Option de direction B

```text
DIRECTION OPTION B
= ADDRESS_M13_DECLARED_RESPONSIBILITY_VALUE_ARCHITECTURE_DOMAIN_CLOSURE

CIBLE
= RCS-C
  et en aval RCS-D / RCS-E / RCS-G / RCS-H
  RELATIVEMENT AU SEUL MODÈLE RR01..RR10 ACTUELLEMENT DÉCLARÉ
```

Question canonique :

```text
QUELS DOMAINES COMPLETS DE VALEURS ET D'ARCHITECTURES,
QUELLES DÉPENDANCES,
QUELLES COMPOSITIONS,
QUELS CLASSIFICATEURS,
ET QUELLE SÉMANTIQUE DE CANONICALISATION

PEUPLENT LE MODÈLE DE RESPONSABILITÉS
RR01..RR10 ACTUELLEMENT DÉCLARÉ ?
```

## 12. Portée exacte de l'option B

L'option B DOIT préserver :

```text
RCS-B     NOT_ESTABLISHED
QU-01     NON RÉSOLUE
```

Tout résultat ultérieur sous B doit être explicitement borné :

```text
RELATIVEMENT AU REGISTRE RR01..RR10 ACTUELLEMENT DÉCLARÉ
```

Il ne doit PAS prétendre :

```text
RCS-C GLOBALE ESTABLISHED
COMPLÉTUDE GLOBALE D'ESPACE DE CANDIDATS M13
AUCUNE RESPONSABILITÉ CONSTITUTIVE ADDITIONNELLE N'EXISTE
```

Si l'option B découvre une difficulté exigeant une responsabilité constitutive
supplémentaire :

```text
RAPPORTER CETTE DÉPENDANCE
NE PAS PROMOUVOIR SILENCIEUSEMENT UN FACTEUR NOUVEAU
NI DÉCLARER RCS-B RÉSOLUE
```

## 13. Relation entre A et B

```text
OPTION A
= CLÔTURE AMONT DE FACTORISATION CONSTITUTIVE

OPTION B
= CLÔTURE AVAL DE DOMAINES,
  CONDITIONNELLE À LA FACTORISATION ACTUELLEMENT DÉCLARÉE
```

Par conséquent :

```text
UN SUCCÈS DE A
PEUT CHANGER LE MODÈLE DE RESPONSABILITÉS
SUR LEQUEL B DOIT OPÉRER

UN SUCCÈS DE B
NE PEUT PAS À SOI SEUL ÉTABLIR RCS-B
```

```text
CETTE DÉPENDANCE EST EXPLICATIVE
ELLE NE SÉLECTIONNE PAS AUTOMATIQUEMENT A
```

## 14. Aucune conclusion de dominance

Ne sont PAS matérialisés :

```text
A DOMINE B
B EST INVALIDE
B EST INTERDITE
```

L'autorité 71 établit deux ouvertures : RCS-B ouverte et RCS-C ouverte. Les deux
directions sont matériellement distinctes et toutes deux recevables.

## 15. Ensemble borné d'options

```text

= COMPLET POUR LA PORTE COURANTE
```

d'orchestrateur nouvelle :

```text
une étude d'invariance d'issue
une étude de dominance
une expérience d'acquisition de preuve
une implémentation
```
